# 科学计算任务运营服务

这是一个面向科研平台、实验室和计算中心的 Python 后端，使用 FastAPI 与 SQLite 管理参数模板、计算任务提交、优先级排队、工作者领取、取消、失败重试、租约恢复、用户配额、结果版本和管理员人工干预记录。服务同时保留用户、角色、会话和审计等基础能力，所有运行数据都在单个本地数据库文件中，不需要另行部署数据库、缓存、消息队列或浏览器界面。

## 已有能力

- 参数模板：保存参数类型、必填项、数值范围、默认值、最大运行时间和最大尝试次数。
- 任务提交：根据模板校验参数，使用用户与幂等键避免重复创建，并保存项目、提交人和输入摘要。
- 排队领取：按优先级和进入队列的顺序分配任务，工作者可声明算法能力并获得有期限的租约。
- 执行回执：工作者可以续租、提交结果或报告失败；可重试错误使用确定的退避时间重新排队。
- 失败恢复：租约过期后可由恢复入口将任务重新排队，达到最大尝试次数的任务转为失败。
- 配额控制：可保存用户、角色或项目的排队数、运行数和每日提交上限；当前提交路径执行用户配额。
- 结果版本：每次成功回执保存不可变结果、指标摘要和内容摘要，任务指向当前结果版本。
- 人工干预：取消、人工重试、优先级调整和批量操作均保留操作者、原因、前后状态和批次标识。
- 登录与角色：基础管理模块提供管理员初始化、用户、角色、会话和细粒度权限。

## 拼车发射方案比较（/api/rideshare）

面向采购的可审计比价后端，比较不同拼车发射方案的每公斤费用，并把卫星尺寸、冗余件和最晚交付日期纳入约束：

- 报价导入：`POST /api/rideshare/quote-batches` 按批次号导入；同一批次号重复导入且内容一致时幂等回放，内容不一致返回 409，绝不覆盖已入库报价；报价更新必须使用新批次号。
- 逐行校验：缺单位、单位无法识别、数值超出范围、非法日期或币种的行逐条返回错误并落库（`ride_quote_row_errors`），合法行正常入库；质量支持 kg/g/lb 等，长度支持 m/cm/mm/in/ft，币种按 ISO 4217 校验。
- 载荷需求：`PUT /api/rideshare/payload-requirements` 定义单件质量、包络尺寸、副本数与冗余件数（总件数 = 副本数 + 冗余件数），更新自动递增版本。
- 候选组合：`POST /api/rideshare/comparisons` 选定报价批次与载荷后生成版本化候选组合；每条分配给出起步费、质量费、小计、总成本与等效每公斤成本，并标注是否满足最晚交付日期（整流罩尺寸允许横截面旋转 90 度）。
- 人工锁定：`POST .../locks` 把若干件载荷锁定到指定报价行（必须填写原因）；重算（`POST .../recompute`）时锁定槽位原样保留，只重新求解未锁定部分；锁定报价行被切出报价范围时重算明确报 409，而不是悄悄改写已提交的论证。
- 版本不可变：每次生成、锁定、解锁、重算都产生新的比较版本（含输入快照、摘要、计算引擎版本），旧版本与已导出报告只读。
- 决策报告：`POST .../reports` 按当前比较版本导出带版本号的报告；同一比较版本重复导出幂等返回原报告，内容带 SHA-256 摘要。
- 来源追溯：响应中每个数字都带 `sources`（如 `quote-row:12#per_kg_price`、`requirement:SAT-A#unit_mass`），可通过 `GET /api/rideshare/quote-rows/{id}` 与版本输入快照逐层核对；`GET .../audit` 返回完整决策审计轨迹。

快速演示：`python -m app.cli rideshare-demo`。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/compute-operations.db`。可以复制 `.env.example` 并通过 `TOWNSHIP_DATABASE_PATH` 指定其他本地路径。

## 数据库初始化与检查

```bash
python -m app.cli init-db
python -m app.cli check-db
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8432
```

健康检查：

```bash
curl -sS http://127.0.0.1:8432/api/system/health
```

计算任务摘要位于 `/api/compute/summary`，模板、配额、提交、领取、回执和人工操作接口统一使用 `/api/compute` 前缀。

## 测试

```bash
python -m pytest
```

测试覆盖参数规则、幂等提交、配额拒绝、优先级领取、能力匹配、租约续期、失败退避、结果版本、取消、人工重试、批量操作和租约恢复，并保留身份与既有科学计算模块的回归用例。

## 编译检查

```bash
python -m compileall -q app tests
```

## API 冒烟

```bash
python -m app.cli smoke
python -m app.cli compute-demo
```

`smoke` 在进程内检查根路径和健康接口，`compute-demo` 会创建示例参数模板、提交一个计算任务并让匹配能力的工作者领取，用于快速确认核心运营链路。

## 目录结构

```text
app/
  compute/         计算模板、配额、任务、结果版本和人工干预
  rideshare/       拼车发射报价导入、候选组合、人工锁定与决策报告
  api/             用户、角色、认证、审计和系统管理接口
  core/            时钟、安全、异常和分页能力
  repositories/    通用 SQLite 查询
  seismic/         既有地震计算示例领域
  services/        身份、审计和通用后台任务服务
  cli.py           初始化、检查和冒烟入口
  database.py      SQLite 连接、事务、表结构与基础权限
tests/             核心、计算运营、拼车比较和身份回归测试
tools/             本地维护脚本
```

## 数据一致性

SQLite 连接启用外键、WAL、busy timeout 和同步写入策略。提交、领取、回执和人工干预使用即时事务；任务领取通过条件更新避免同一条排队记录被重复领取。服务保存 UTC 时间字符串，测试可以注入固定时钟验证退避、租约到期和跨日配额。会话令牌只保存摘要，审计与人工干预记录不会写入明文密码或令牌。
