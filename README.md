# 科学计算任务运营服务

这是一个面向科研平台、实验室和计算中心的 Python 后端，使用 FastAPI 与 SQLite 管理参数模板、计算任务提交、优先级排队、工作者领取、取消、失败重试、租约恢复、用户配额、结果版本和管理员人工干预记录。服务同时保留用户、角色、会话和审计等基础能力，所有运行数据都在单个本地数据库文件中，不需要另行部署数据库、缓存、消息队列或浏览器界面。

## 已有能力

- 参数模板：保存参数类型、必填项、数值范围、默认值、最大运行时间和最大尝试次数。
- 任务提交：根据模板校验参数，使用用户与幂等键避免重复创建，并保存项目、提交人和输入摘要。
- 排队领取：按优先级和进入队列的顺序分配任务，工作者可声明算法能力并获得有期限的租约。
- 执行回执：工作者可以续租、提交结果或报告失败；可重试错误使用确定的退避时间重新排队。
- 失败恢复：租约过期后可由恢复入口将任务重新排队，达到最大尝试次数的任务转为失败。
- 配额控制：可保存用户、角色或项目的排队数、运行数和每日提交上限；当前提交路径执行用户配额。
- 结果版本：每次成功回执保存不可变结果、指标摘要和内容摘要，任务指向当前结果版本。
- 人工干预：取消、人工重试、优先级调整和批量操作均保留操作者、原因、前后状态和批次标识。
- 登录与角色：基础管理模块提供管理员初始化、用户、角色、会话和细粒度权限。
- 拼车发射采购比较：按批次导入报价、定义载荷需求、生成候选组合与成本分解、人工锁定组合、重算未锁定部分并导出版本化决策报告，全程可审计追溯（见下文）。

## 拼车发射采购比较器

`/api/procurement` 前缀提供面向采购团队的拼车发射方案比较能力，所有数字均可追溯来源与计算版本。

- 报价导入：`POST /api/procurement/quote-batches` 按批次号导入报价行（供应商、型号、发射日期、价格与计价单位、可用运力、包络尺寸）。同一批次号重复导入且内容一致时幂等重放（返回 200 与 `replayed: true`）；内容不一致时返回 409，已导入批次不可改写，报价更新必须使用新批次号。任何一行缺少计价单位、缺字段或数值超出范围时，整个批次不导入，并逐行返回错误（行号、字段、错误码）。
- 当前报价簿：`GET /api/procurement/quotes/current` 对同一供应商、型号、发射日期取最新批次的报价；历史报价行保留在库中用于追溯。
- 载荷需求：`POST /api/procurement/requirements` 定义卫星尺寸、单星质量、正选数量、冗余数量与最晚交付日期；`PUT` 更新会使版本号递增并记录审计事件，历史计算版本中的需求快照不受影响。
- 候选组合：`POST /api/procurement/requirements/{id}/calculations` 生成新的计算版本。算法 `combo-v1` 先按尺寸包络、发射日期不晚于最晚交付日期、运力约束过滤报价，再按币种分组，用最低单价、最少发射次数、最早交付三种确定性策略贪心分配卫星（含冗余件），逐行分解成本（单价、分摊公斤数、行成本、总成本、每公斤费用、每星费用）。锁定的组合原样结转到新版本，未锁定部分按当前报价簿重新计算，旧版本的未锁定组合标记为 `stale`。
- 人工锁定：`POST /api/procurement/candidates/{id}/lock`（`/unlock`）锁定或解锁最新计算版本中的组合，需填写操作者与原因；同一需求同一时间最多一个锁定组合。
- 决策报告：`POST /api/procurement/requirements/{id}/reports` 导出带递增版本号的不可变报告，包含需求快照、计算版本、报价批次引用、锁定组合与全部候选的完整分解；`GET /api/procurement/reports/{id}` 永远返回导出时的内容。
- 追溯：`GET /api/procurement/candidates/{id}` 返回每个数字的来源（报价行 ID、批次号、报价摘要）与计算版本（运行版本、算法版本、需求版本、报价集摘要）；`GET /api/procurement/events` 提供导入、需求变更、计算、锁定、报告导出的完整审计事件流。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/compute-operations.db`。可以复制 `.env.example` 并通过 `TOWNSHIP_DATABASE_PATH` 指定其他本地路径。

## 数据库初始化与检查

```bash
python -m app.cli init-db
python -m app.cli check-db
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8432
```

健康检查：

```bash
curl -sS http://127.0.0.1:8432/api/system/health
```

计算任务摘要位于 `/api/compute/summary`，模板、配额、提交、领取、回执和人工操作接口统一使用 `/api/compute` 前缀。

## 测试

```bash
python -m pytest
```

测试覆盖参数规则、幂等提交、配额拒绝、优先级领取、能力匹配、租约续期、失败退避、结果版本、取消、人工重试、批量操作和租约恢复，并保留身份与既有科学计算模块的回归用例。采购比较器覆盖批次幂等重放与冲突、逐行校验错误、候选组合成本分解、约束过滤、锁定与解锁、报价更新后历史论证不变、报告版本化与不可变性，以及审计事件流。

## 编译检查

```bash
python -m compileall -q app tests
```

## API 冒烟

```bash
python -m app.cli smoke
python -m app.cli compute-demo
python -m app.cli procurement-demo
```

`smoke` 在进程内检查根路径和健康接口，`compute-demo` 会创建示例参数模板、提交一个计算任务并让匹配能力的工作者领取，用于快速确认核心运营链路。`procurement-demo` 会导入一个演示报价批次、创建载荷需求、生成候选组合、锁定最低成本组合并导出第一份决策报告。

## 目录结构

```text
app/
  compute/         计算模板、配额、任务、结果版本和人工干预
  procurement/     拼车发射报价批次、载荷需求、候选组合、锁定与决策报告
  api/             用户、角色、认证、审计和系统管理接口
  core/            时钟、安全、异常和分页能力
  repositories/    通用 SQLite 查询
  seismic/         既有地震计算示例领域
  services/        身份、审计和通用后台任务服务
  cli.py           初始化、检查和冒烟入口
  database.py      SQLite 连接、事务、表结构与基础权限
tests/             核心、计算运营、采购比较和身份回归测试
tools/             本地维护脚本
```

## 数据一致性

SQLite 连接启用外键、WAL、busy timeout 和同步写入策略。提交、领取、回执和人工干预使用即时事务；任务领取通过条件更新避免同一条排队记录被重复领取。服务保存 UTC 时间字符串，测试可以注入固定时钟验证退避、租约到期和跨日配额。会话令牌只保存摘要，审计与人工干预记录不会写入明文密码或令牌。
